GPI Case Summariser

AI-generated summaries of resolved payment investigation cases — from 15-minute manual reads to 60-second structured output

Platform HSBC Technology 2025–2026

Context

The Problem

🗂️
Case history is unstructured and slow to read When reopening a case or looking for similar precedents, investigators must manually dig through raw, unstructured archival records. Reading and interpreting a single case takes 5 to 15 minutes.
🌍
No consistent format across markets Case records from different markets are entered differently — no standard structure, no shared summary format. Comparing or learning from cases across regions is impractical.
🧠
Precedent held in individual memory Resolution logic and similar-case knowledge lives with individual investigators, not in the system. It's lost on rotation and hard to transfer.

Product

The Solution

  • A Summarise button on the Pega home screen — accessible without navigating away from the main workspace.
  • Investigator enters a Case ID and clicks Summarise. The system retrieves the full case history for that ID.
  • AI reads unstructured case data — case notes, SWIFT messages, exception fields, resolution details — and returns a structured 7-field plain-English summary in under 60 seconds.
  • Output fields: case overview, parties involved, exception type, actions taken, resolution, time-to-resolve, reference numbers.
  • Useful for case reopens (quickly reconstruct what happened), finding similar cases (scan precedents without manual reading), and cross-market consistency (standardised summary format regardless of how the original record was entered).

Walkthrough

How It Works

1

Investigator opens Pega home screen

The Summarise button is present on the home screen — no navigation required. Accessible from the main workspace at any point in the investigator's workflow.

2

Enters Case ID and clicks Summarise

Single input. Investigator enters the Case ID of any case — active, resolved, or archived — that they want to review or reference.

3

System retrieves full case history

The system pulls the complete case history for that ID — case notes, SWIFT message fields, exception metadata, and resolution details — directly from the archival table. No manual copy-paste.

4

AI generates a structured 7-field summary

Output: case overview, parties, exception type, actions taken, resolution, time-to-resolve, and reference numbers — plain English, consistently formatted.

5

Investigator reviews and acts

Summary is advisory — it doesn't override Pega workflow or auto-populate fields. Used for case reopens (reconstruct what happened), finding similar cases (scan precedents fast), or cross-market consistency (same structured format regardless of how the original record was entered).
