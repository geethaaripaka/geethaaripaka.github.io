Context

The Problem

Users: BA and technical teams.

🔎
Answers scattered across sources BA and technical teams had to search operational guides and training documents across multiple places to answer a single question.
⚠️
Generic AI isn't trustworthy here In regulated payment operations, an answer must come from our own documentation and be verifiable.
⏱️
Slow lookups block delivery Time spent hunting for procedures, SLA rules and corridor guidance slowed down BA and technical teams.

Insight

The Insight

GPI questions come in two shapes. Some are conceptual ("how do we handle a recall request?"), where users phrase things differently from the docs. Others are exact-reference, where specific message names, identifiers and procedural terms must match precisely. One retrieval method rarely handles both, and that shaped the whole design.

Decision

Key Decision: How to Retrieve

Questions needed both conceptual matches and exact matches on message names, identifiers and procedural terms. We chose hybrid retrieval, combining semantic matching for meaning with lexical matching for exact terms, then filtering and ranking for precision. It's more complex to tune than a single method, but in payments operations, missing an exact term produces a confidently wrong answer, and that costs more than engineering effort.

Product

The Solution

A grounded assistant that answers only from indexed GPI guides, with citations and a preview of the exact source passage so users can verify the guidance themselves.

How it works

Architecture

Ingestion

01
Operational guides and training documents are uploaded to a Google Cloud Storage bucket as the source corpus.
02
AI-assisted ingestion parses, normalises and chunks the documents.
03
Chunks are loaded into PostgreSQL as indexed chunks: a query-ready knowledge base.

Query

01
A BA asks a question in the Flask-based chat app (RAG chatbot + APIs), which validates the user session and tracks chat history and feedback.
02
If it's a follow-up, the app rewrites it into a clear standalone query using recent conversation context.
03
The query is converted into a representation suitable for semantic search.
04
Hybrid retrieval runs over the indexed chunks:
  • semantic matching for meaning-based relevance
  • lexical/text matching for exact terminology (message names, identifiers, procedural terms)
  • filtering and ranking logic to improve precision
05
The highest-ranked chunks are returned as evidence and combined with the question into a grounded prompt.
06
GPT-4o generates the answer from that evidence only, with citations linked back to the original sources.
07
The answer is shown with citations, source preview and feedback options.

Decisions

Product Decisions

  • Grounded-only answers: responds from indexed guides, never generic knowledge.
  • Source preview + feedback loop: Helpful / Incomplete / Incorrect with an optional comment; builds trust with users and turns answer quality into a measurable signal.
  • Auto-generated workflow diagrams: many questions are about processes, and a flowchart answers faster than paragraphs.
  • Query rewriting for follow-ups: users ask in conversations, not single questions, so follow-ups need to retrieve as well as the first question.
  • Export to PDF/Word: answers need to live in each team's record-keeping trail, not just on screen.
